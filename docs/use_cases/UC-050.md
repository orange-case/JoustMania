## History

The operator set a target backend and a strategy in the `rollout` flag set; the agent's infrastructure loop checked Bluetooth fitness (event gap, dropped events, movement update rate) on the `controller.bluetooth_health` span and advanced `current_controller_count` stage by stage (0, 1, 3, 6, all) through the flag service, recording each cycle on an `agent.infrastructure.decision` span. A failing stage rolled back ([UC-051](UC-051.md)). Parked on 2026-10-19, retired by #2784.
